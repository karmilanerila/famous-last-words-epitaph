A program that writes the funniest one-line famous last words as a tombstone epitaph (at most 150 characters) to `/output/entry.txt`.

The epitaph:

> I asked for one more minute. They gave me forever.

A dying plea for "one more minute", granted literally — the twist lands in one read, reads like something carved in stone, and is short enough to quote to a friend.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (50 characters, one line) to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
